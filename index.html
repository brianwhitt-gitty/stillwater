Voice

For instant playback on your phone, install a high-quality voice. iPhone: Settings › Accessibility › Spoken Content › Voices › English, choose a male voice and download its Enhanced or Premium version. Android: Settings › Accessibility › Text-to-speech output, then install voice data for your engine. Reload this page and pick it under Device voices. These voices run on your phone and start instantly; Norman also starts quickly on phones; the studio voices sound richer but take longer to prepare.

Private by design

  • Nothing is savedYour text lives only in this open tab. The page has no account, no server and no storage. Refresh or close it and the meditation is gone. Only the voice model itself is kept in your browser’s cache.
  • Nothing is sentThe page makes no network requests with your words. The studio voice engine can only load this page’s own files and refuses requests to any other site.
  • Voices run on your deviceNorman and the studio voices are AI models running inside this tab. Device voices marked online send text to Google or Microsoft, so they stay hidden unless you untick the box above.
  • Spellcheck is offThe text box turns off browser spellcheck, which on some setups sends what you type to a cloud service.
Voices: Norman (Piper, trained on public-domain LibriVox recordings) and Kokoro-82M by hexgrad (Apache-2.0), run with Piper's phonemizer, kokoro-js 1.2.1 and ONNX Runtime Web. All files are hosted with this page, and nothing is loaded from anywhere else.
